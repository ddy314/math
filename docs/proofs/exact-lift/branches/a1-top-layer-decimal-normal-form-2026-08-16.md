# A1 top-layer decimal normal form — 2026-08-16

本文继续 `a1-top-layer-uniform-cone-2026-08-16.md`，把最高层

\[
s_1=g+2
\]

从一个 `(m_1,k)` 斜锥进一步压成四个十进制端点同时贴边的正规形。

核心结果：

\[
\boxed{1-t<5\cdot10^{-2k}},
\]

进而

\[
\boxed{m_1\ge2k,\qquad n_2\ge2k}
\]

并且两个取等边界都化成常数偏移族。

本文结论均为 **已严格完成**。

---

## 1. 从 `\lambda` 指数锥得到 `t` 的极端贴边

最高层已经证明

\[
\lambda<\frac34 10^{-2k}.
\tag{1}
\]

记

\[
a=10^{-2k},
\qquad
\zeta=10^{-k-2g}.
\]

前文 contact 给出

\[
(1-\lambda)^2
<
(1+c_Q)(t^2+a+\zeta^2),
\tag{2}
\]

其中

\[
1+c_Q=\left(1+\frac1Q\right)^2.
\]

因为 `1/Q\le\lambda`，

\[
1+c_Q\le(1+\lambda)^2.
\]

故由 (2)：

\[
t^2
>
\left(\frac{1-\lambda}{1+\lambda}\right)^2
-a-\zeta^2.
\tag{3}
\]

而

\[
\left(\frac{1-\lambda}{1+\lambda}\right)^2
=
1-\frac{4\lambda}{(1+\lambda)^2}
>1-4\lambda.
\]

由 (1)：

\[
4\lambda<3a.
\]

又因 `g\ge0`，

\[
\zeta^2=10^{-2k-4g}\le a.
\]

所以 (3) 给出

\[
\boxed{t^2>1-5a.}
\tag{4}
\]

因为 `0<t<1`，有 `t>t^2`，因此

\[
\boxed{
 t>1-5\cdot10^{-2k}.
}
\tag{5}
\]

等价地

\[
\boxed{
1-t<5\cdot10^{-2k}.
}
\tag{6}
\]

---

## 2. `t` 的四端点乘积分解

令

\[
A_2^*=\frac{a_2}{10^{n_2}}
\in\left[\frac1{10},1\right),
\]

\[
B_1^*=\frac{b_1}{10^{m_1}}
\in\left[\frac1{10},1\right),
\]

\[
B_2^*=\frac{b_2}{10^{m_2}}
\in\left[\frac1{10},1\right),
\]

以及由于 `s_1=g+2`，

\[
A_1^*
=\frac{a_1}{10^{n_1-1}}
\in[1,10).
\]

直接代入

\[
t=\frac{a_2b_1}{b_2 10^k a_1}
\]

并使用

\[
n_2=m_2+k+g,
\qquad
n_1-1=m_1+g+1,
\]

得到精确乘积

\[
\boxed{
 t
=A_2^*\,B_1^*\,
\frac1{10B_2^*}\,
\frac1{A_1^*}.
}
\tag{7}
\]

四个因子都严格为正且不超过 `1`。

由 (5)，乘积大于 `1-5a`。因此每一个因子都必须单独大于 `1-5a`：

\[
\boxed{
A_2^*>1-5a,
\qquad
B_1^*>1-5a,
}
\tag{8}
\]

\[
\boxed{
\frac1{10B_2^*}>1-5a,
\qquad
\frac1{A_1^*}>1-5a.
}
\tag{9}
\]

这说明最高层四个十进制 mantissa 同时贴住各自最有利端点。

## 3. 两个上端点的整数 deficit

由 (8)：

\[
a_2>(1-5a)10^{n_2},
\]

所以正整数

\[
\boxed{d_2:=10^{n_2}-a_2}
\]

满足

\[
\boxed{
1\le d_2<5\cdot10^{n_2-2k}.
}
\tag{10}
\]

同理正整数

\[
\boxed{d_1:=10^{m_1}-b_1}
\]

满足

\[
\boxed{
1\le d_1<5\cdot10^{m_1-2k}.
}
\tag{11}
\]

由于 `d_1,d_2\ge1`，右侧必须大于 `1`。

若 `m_1<2k`，则 `m_1-2k\le-1`，(11) 右侧至多 `1/2`，矛盾。因此重新得到

\[
\boxed{m_1\ge2k.}
\tag{12}
\]

更重要的是 (10) 同样给出此前没有的第二块约束：

若 `n_2<2k`，则右侧至多 `1/2`，矛盾。所以

\[
\boxed{n_2\ge2k.}
\tag{13}
\]

因为

\[
n_2=m_2+k+g,
\]

等价于

\[
\boxed{m_2+g\ge k.}
\tag{14}
\]

所以最高层真正的移动前缀锥现在是二维交：

\[
\boxed{
m_1\ge2k,
\qquad
m_2+g\ge k.}
\tag{15}
\]

## 4. 两个下端点的窄条带

由 (9)：

\[
B_2^*<\frac1{10(1-5a)},
\]

因此

\[
10^{m_2-1}
\le b_2
<
\frac{10^{m_2-1}}{1-5a}.
\]

定义非负整数

\[
\boxed{e_2:=b_2-10^{m_2-1}\ge0.}
\]

则

\[
\boxed{
0\le e_2
<
\frac{5a}{1-5a}
10^{m_2-1}.
}
\tag{16}
\]

同理

\[
A_1^*<\frac1{1-5a},
\]

定义

\[
\boxed{e_1:=a_1-10^{n_1-1}\ge0,}
\]

得到

\[
\boxed{
0\le e_1
<
\frac{5a}{1-5a}
10^{n_1-1}.
}
\tag{17}
\]

所以最高层四个整数可以统一写成

\[
\boxed{
\begin{aligned}
b_1&=10^{m_1}-d_1,\\
a_2&=10^{n_2}-d_2,\\
b_2&=10^{m_2-1}+e_2,\\
a_1&=10^{n_1-1}+e_1,
\end{aligned}
}
\tag{18}
\]

其中 `d_1,d_2` 为正且满足 (10)–(11)，`e_1,e_2` 非负且满足 (16)–(17)。

这是最高层的 **extreme decimal normal form**。

## 5. 边界 `m_1=2k` 只剩四个常数偏移

若

\[
\boxed{m_1=2k,}
\]

则 (11) 化成

\[
1\le d_1<5.
\]

因此

\[
\boxed{
d_1\in\{1,2,3,4\}.}
\]

即

\[
\boxed{
 b_1=10^{2k}-j,
\qquad
j\in\{1,2,3,4\}.
}
\tag{19}
\]

所以 `m_1=2k` 不再是一整条任意 denominator 边界，而只有四个无界常数-offset 家族。

---

## 6. 边界 `n_2=2k` 的更强刚性

若

\[
\boxed{n_2=2k,}
\]

则 (10) 给出

\[
1\le d_2<5,
\]

故

\[
\boxed{
d_2\in\{1,2,3,4\},}
\]

即

\[
\boxed{
 a_2=10^{2k}-h,
\qquad
h\in\{1,2,3,4\}.
}
\tag{20}
\]

另一方面 `n_2=m_2+k+g`，所以边界条件等价于

\[
\boxed{m_2=k-g.}
\tag{21}
\]

把它代入 (16)：

\[
e_2
<
\frac{5}{1-5a}
10^{-2k+m_2-1}
=
\frac{5}{1-5a}
10^{-k-g-1}.
\]

因为 `k\ge1,g\ge0,a\le1/100`，右侧严格小于 `1`。

而 `e_2` 是非负整数，所以

\[
\boxed{e_2=0.}
\]

即

\[
\boxed{
 b_2=10^{m_2-1}.
}
\tag{22}
\]

如果 `m_2\ge2`，则 `b_2` 被 `10` 整除。原问题要求

\[
\gcd(a_2,b_2)=1,
\]

所以 `a_2` 必须与 `10` 互素。

对

\[
a_2=10^{2k}-h,
\qquad h\in\{1,2,3,4\},
\]

只有 `h=1,3` 给出末位 `9,7`。因此

\[
\boxed{
 m_2\ge2,\ n_2=2k
\Longrightarrow
h\in\{1,3\}.
}
\tag{23}
\]

若 `m_2=1`，则 `b_2=1`，不需要这个末位筛选。

---

## 7. 当前最高层正规形

最高层 `s_1=g+2` 现在必须同时满足：

\[
\boxed{m_1\ge2k,\qquad n_2\ge2k,}
\]

并具有 (18) 的四端点表示。

两个最外边界进一步退化成：

\[
\boxed{
m_1=2k
\Longrightarrow
b_1=10^{2k}-j,\ j\in\{1,2,3,4\},
}
\]

\[
\boxed{
n_2=2k
\Longrightarrow
b_2=10^{m_2-1},\quad
 a_2=10^{2k}-h,\ h\in\{1,2,3,4\},
}
\]

且 `m_2\ge2` 时后者只剩 `h\in\{1,3\}`。

因此下一步最值得优先攻击的是：

1. `m_1=2k` 的四个 `j` 常数核；
2. `n_2=2k` 的 `h=1,3`（以及 `m_2=1` 的极小例外）常数核；
3. 双边界 `m_1=n_2=2k`，它同时具有两套常数偏移，最有希望直接由局部同余或整数平方证书关闭。

本文仍未把这些无界常数-offset 家族误写成有限枚举。
