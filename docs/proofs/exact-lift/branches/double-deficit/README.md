### 1. long one-channel core 的 sharp lower

shared-defect ledger 把旧 individual windows 统一重算后得到

\[
\boxed{
\frac{\log_{10}v_2}{S}\ge1-\delta-o(1).}
\]

这条 sharp lower 是后续所有 threshold 扩宽的共同输入。

### 2. denominator `qZ` product lock

exact congruence为

\[
\boxed{
2^HqZ\equiv5^Tb_1 10^{m_2}\pmod{v_2}.}
\]

shared-defect sharpen 给

\[
\frac{\log(qZ)}S\le2z_*+\delta+o(1),
\qquad
\frac{\log v_2}S\ge1-\delta-o(1),
\]

故

\[
\boxed{
\delta<\frac12-z_*
=0.191116422381969\ldots
\Longrightarrow 0<qZ<v_2.}
\]

因此模条件升级成 ordinary least-residue equality。

### 3. cofactor projective shape 全域退化成 common-scale ray

写

\[
V=v_1v_2,
\qquad
\tau_i=b_i/v_i.
\]

fixed S-unit phase / factor split 中两个 cofactor candidates满足

\[
U\mid\tau_2\tau_1'-\tau_2'\tau_1.
\]

sharp fixed-width determinant box与

\[
\boxed{
\frac{\log(UV)}S\ge1+U_*-\delta-o(1)}
\]

共同证明：在现行 quantitative one-channel 的整个 `delta<=1/2` 作用域中，`tau_2/tau_1` 至多一个。于是 exact denominator data 必落在唯一 common-scale ray

\[
\boxed{
(b_1,b_2,b_3,q,\gamma)
=(\ell\bar b_1,\ell\bar b_2,\ell\bar b_3,
\ell\bar q,\ell^2\bar\gamma).}
\]

rough `gamma` 的 movable part因此只是 homogeneous common denominator scale，不再是第二个独立 projective shape。candidate-specific denominator/S-unit entropy相应 sharpen 为

\[
\boxed{
N_{\rm den/SU}
\le10^{(\sigma_S+R/2)S+o(S)}.}
\]

uniform worst-case coefficient仍可能由 `sigma_S` 支配，因此这一步本身不产生 strict gap。

### 4. S-unit phase 是真正的 Euclidean remainder system

在整个 corrected one-channel neighborhood 中，shared-defect comparison给

\[
0<Z,V<5^T.
\]

所以

\[
2^HZ=5^TU+V
\]

本身就是 Euclidean division：

\[
\boxed{
U=\left\lfloor\frac{2^HZ}{5^T}\right\rfloor,
\qquad
V=2^HZ\bmod5^T,
\qquad
Z=[2^{-H}V]_{5^T}.}
\]

因此固定 `(H,T,V)` 后 `(U,Z)` 至多唯一；Farey/S-unit phase 的 moving projective coordinate可压成单个 remainder `V`。

### 5. direct source quotient lock

固定 `v_2,b_1` 后，先由 `v_1|b_1` 枚举 divisor-many `v_1`，故 `V=v_1v_2`；Euclidean lock恢复 `U,Z`。denominator concat再给

\[
Uq\equiv b_1 10^{m_2}\pmod{v_2}.
\]

shared-defect sharp lower为

\[
\boxed{
\frac1S\log\frac{v_2}{q}
\ge U_*-\frac32\delta-o(1).}
\]

故

\[
\boxed{
\delta<\frac{2U_*}{3}
=0.460744281587979\ldots
\Longrightarrow
q=[U^{-1}b_1 10^{m_2}]_{v_2}.}
\]

fixed `(v_2,b_1)` 的 denominator/S-unit fiber 因而只剩 divisor entropy / exact reconstruction。

### 6. numerator side 同步 collapse 到 `0.460744...`

旧 carry-`U` × pair-max theorem已有 exact transverse period

\[
M_{UV}=Uv_2,
\qquad (U,v_2)=1.
\]

新的 shared-defect sharpen 给

\[
\boxed{
\frac{\log(Uv_2)}S
\ge1+U_*-\frac32\delta-o(1).}
\]

所以 fixed `(R_0,g_0,a_2)` fiber 的 `A_12` uniqueness threshold 从 `0.238062...` 扩到

\[
\boxed{
\delta<\delta_{UV}^{\sharp}
:=\frac{2U_*}{3}
=0.460744281587979\ldots.}
\]

同时 sharp `v_2` lower 把：

- short suffix `a_2` uniqueness 扩到整个 `delta<1/2` one-channel neighborhood；
- gap-fraction rational reconstruction uniqueness也扩到整个 `delta<1/2` one-channel neighborhood。

因此 fixed denominator/S-unit data 下

\[
\boxed{
N_{\rm num}(S;\delta)=10^{o(S)}
\qquad
(\delta<0.460744281587979\ldots).}
\]

source-square × pair-max 的独立 consistency threshold也从 `0.142505...` 提升到

\[
\boxed{
\delta<\frac{2z_*}{3}
=0.205922385078687\ldots,}
\]

但它已被更强的 `Uv_2` period覆盖。

### 7. 当前 canonical terminal residual

在 `delta<0.460744281587979...` 中，fixed denominator/S-unit 后已没有 positive-linear numerator freedom；在整个 `delta<=1/2` one-channel neighborhood 中，fixed phase/factor split 的 denominator projective shape也只有唯一 common-scale ray。

因此 corrected canonical terminal 的 residual 可以压缩成

\[
\boxed{
\text{scale-quotiented moving S-unit remainder }V
\quad+\quad
\text{homogeneous common scale }\ell.}
\]

其中 `ell` 不是新的 projective payer。下一真正目标是直接排除 moving `V` / Farey-S-unit primitive phase，或证明其与 pair-max Gaussian orientation / decimal shell 全局不相容。

这些结果仍不推出 DD emptiness 或 explicit strict slope gap，也不覆盖更低 post-tail / non-canonical dominant states。
