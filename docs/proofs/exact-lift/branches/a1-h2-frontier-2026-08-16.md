# A1 `h=2` frontier — 2026-08-16

本文开始逐层处理 universal prefix collapse 后剩余的

\[
h:=s_1-g\in\{-1,0,1,2\}.
\]

先研究最上层

\[
\boxed{h=2.}
\]

这一层的特殊点是：完整拼接比 `R` 的十进制下边界，恰好位于 `r_2` 的十进制上边界之上。因此 `r_2` 被迫从下方逼近一个整数十次幂，可以用有理间距给第二分母 `b_2` 下界。

本文结论均为 **已严格完成**。

---

## 1. `h=2` 的边界十次幂

`h=2` 意味着

\[
s_1=g+2.
\]

完整拼接比 `R=\alpha/\beta` 的分子、分母总位数差为

\[
(s_1+s_2+s_3)
=(g+2)+(k+g)-g
=k+g+2.
\]

因此位数窗给出

\[
\boxed{R>10^{k+g+1}.}
\tag{1}
\]

另一方面

\[
s_2=k+g,
\]

所以

\[
\boxed{r_2<10^{k+g+1}.}
\tag{2}
\]

定义整数十次幂

\[
\boxed{L_0:=10^{k+g+1}.}
\]

则

\[
\boxed{R>L_0>r_2.}
\tag{3}
\]

---

## 2. 球面差强迫 `r_2` 贴近 `L_0`

由球面

\[
R^2=r_1^2+r_2^2+r_3^2
\]

和 `R>L_0`：

\[
L_0^2-r_2^2
<r_1^2+r_3^2.
\]

又

\[
L_0^2-r_2^2
=(L_0-r_2)(L_0+r_2)
>L_0(L_0-r_2),
\]

所以

\[
\boxed{
L_0(L_0-r_2)<r_1^2+r_3^2.
}
\tag{4}
\]

因为

\[
r_2=\frac{a_2}{b_2}
\]

已经既约，而 `L_0` 是整数，且 `r_2<L_0`，故

\[
L_0-r_2
=\frac{L_0b_2-a_2}{b_2}
\ge\frac1{b_2}.
\]

代入 (4)：

\[
\boxed{
b_2>rac{L_0}{r_1^2+r_3^2}.}
\tag{5}
\]

## 3. 使用 universal carrier saturation 控制分母

`a1-universal-prefix-collapse-2026-08-16.md` 已证明整个 A1 都有

\[
r_1^2<5\cdot10^{2g+2}+5.
\tag{6}
\]

同时第三分数位数窗给出

\[
r_3^2<10^{2-2g}.
\tag{7}
\]

对 `g\ge0`，

\[
5\cdot10^{2g+2}+5+10^{2-2g}
<7\cdot10^{2g+2}.
\]

所以

\[
\boxed{r_1^2+r_3^2<7\cdot10^{2g+2}.}
\tag{8}
\]

把 (8) 与 `L_0=10^{k+g+1}` 代入 (5)：

\[
\boxed{
b_2>
\frac{10^{k+g+1}}{7\cdot10^{2g+2}}
=
\frac{10^{k-g-1}}7.
}
\tag{9}
\]

由于 `1/7>1/10`，若 `k-g-1\ge1`，则

\[
b_2>10^{k-g-2},
\]

从而

\[
\boxed{m_2\ge k-g-1.}
\tag{10}
\]

若右端非正，当然只保留普遍事实 `m_2\ge1`。统一可写成

\[
\boxed{m_2\ge\max(1,k-g-1).}
\tag{11}
\]

## 4. Outer-contact 中第一分母长度被 `g` 控制

`a1-discriminant-sign-cones-2026-08-16.md` 对 outer-contact

\[
P-R\ge r_3
\]

已证明

\[
m_1+m_2\le k+2g+h+2.
\]

在 `h=2` 中：

\[
\boxed{m_1+m_2\le k+2g+4.}
\tag{12}
\]

若 `k-g-1\ge1`，结合 (10)：

\[
m_1
\le
k+2g+4-(k-g-1)
=3g+5.
\]

所以

\[
\boxed{
P-R\ge r_3,\ h=2,\ k\ge g+2
\Longrightarrow
m_1\le3g+5.
}
\tag{13}
\]

在剩余 `k\le g+1` 区域，`k` 本身已经由 `g` 线性控制；所以整个 `h=2` outer 支都进入 `g`-controlled prefix cone。

更粗地说，outer `h=2` 不再允许 `m_1,k` 与 `g` 完全独立增长。

## 5. `r_1` 的 mantissa 也被压进低端窄窗

`h=2` 的位数窗本来只给

\[
r_1>10^{g+1}.
\]

而 universal carrier saturation 的 (6) 给

\[
r_1<\sqrt{5\cdot10^{2g+2}+5}.
\]

所以：

\[
\boxed{
10^{g+1}
<r_1
<10^{g+1}\sqrt{5+5\cdot10^{-2g-2}}.
}
\tag{14}
\]

特别地，当 `g` 增长时，归一化 mantissa

\[
\frac{r_1}{10^{g+1}}
\]

被压在

\[
1<\frac{r_1}{10^{g+1}}<\sqrt5+o(1).
\]

所以 `h=2` 并没有占满一个十倍 decade；它只允许最靠低端的约 `1` 到 `2.24` 区间。

---

## 6. 泛型 `k+2g>=3` 中 `r_2` 同时进入高 mantissa

同一 universal prefix collapse 还给出

\[
t:=\frac{r_2}{10^kr_1}>\sqrt{\frac{24}{101}}>0.487
\]

当

\[
k+2g\ge3.
\]

结合 `r_1>10^{g+1}`：

\[
\boxed{
r_2>0.487\cdot10^{k+g+1}.}
\tag{15}
\]

而由位数窗 `r_2<10^{k+g+1}`。

因此在 `h=2` 泛型区域，两个前缀分数必须同时满足互补的 mantissa 刚性：

\[
1<\frac{r_1}{10^{g+1}}\lesssim2.24,
\]

\[
0.487<\frac{r_2}{10^{k+g+1}}<1.
\]

这会成为后续对 `h=2` 做 denominator-gap / decimal-shift 同余时的实数窗口。

---

## 7. 当前意义

`h=2` 已经从一个无界位数层进一步压成：

- `r_1` 只能位于其 decade 的低 mantissa 端；
- `r_2` 在泛型区域只能位于其 decade 的高 mantissa 端；
- `b_2` 必须满足显式下界 (9)–(11)；
- outer-contact 中 `m_1\le3g+5`（当 `k\ge g+2`），其余区域本身有 `k\le g+1`。

这仍未构成 `h=2` 的全局空性证明，但已经把该层压入一个明显更窄的 `g`-controlled frontier。
