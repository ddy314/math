# 43. 研究结论

这道题目前已经不再是“一个巨大的、无结构的十进制拼接丢番图方程”。

它已经被压缩成三个相当具体的终端问题。

\(A_2\) 的难点是：

\[
\boxed{
\text{高阶 source Hensel 接触能否与真实十进制窗口长期共存？}
}
\]

DD 的难点是：

\[
\boxed{
\text{所有强制五进 resonance 的高层消失后，
阈值以下的 resonance/non-resonance 锥能否仍随前缀高度无界增长？}
}
\]

\(A_1\) 的难点是：

\[
\boxed{
\text{在 Gaussian descent 完全失效的 saturated 平面中，
decimal shift }g\text{ 能否无界？}
}
\]

现阶段最值得优先攻击 DD。

其优先级来自这样一个事实：第 27 节已经首次把局部 resonance 数据转成了 prefix-uniform 的全局高度矛盾。原顶部的结构是

\[
\text{极端不对称}
+
\text{短 numerator block}
+
\text{near-square}
+
\text{双 Hensel resonance}
+
\text{near-}2,5\text{-smooth}.
\]

这个最顶层及其下方的单五进 resonance 带现已全部排除，并先得到中间相对界

\[
n_3\le8S_{12}.
\]

其中五进入口以上的两个 non-resonance 状态已经全部排除：

\[
\Delta_5<0
\quad\text{与}\quad
\Delta_5>0
\quad\text{均为空}.
\]

入口以上唯一剩余的 resonance 支还带有加权赋值惩罚。原先可能达到的最高整数层
\(n_3=8S_{12}+5\) 已经排除：无界的 \(t_2\ge2\) 子锥与
\(3\mid m_3\) 的高度上界冲突，其余二进位置则最终只留下

\[
(S,m_3)=(4,17),(5,21),
\]

并在两处都得到 \(\kappa>10QG\) 的整数矛盾。

继续保留加权 \(m_3\) 界后，入口以上的 \(t_2\ge2\) 无界子锥已经整体
降到 \(n_3\le8S_{12}\)。所以当前最高层 \(n_3=8S_{12}+4\) 只可能
来自 \(t_2=1\)，并且被严格压成十个 \((S,m_3)\) 尺寸；所有尺寸还
共同强迫一个 denominator 长度为 \(1\)、另一个为 \(S-1\) 的极端
前缀位数形状。随后精确余因子证书穷尽 225 个允许赋值元组：每个元组
都要求一个显式短区间包含指定奇数倍的 \(2^h\)，但所有区间均为空。
因此 \(n_3=8S_{12}+4\) 已排除，并得到上述新界。

同一证书随后改用不依赖极端位数形状的一般界 \(G<10^S\)。层
\(n_3=8S_{12}+3\) 与 \(n_3=8S_{12}+2\) 分别只留下 32、59 个
尺寸和 2677、14095 个允许赋值元组；对应余因子区间仍全部为空。
因此这两个层也已排除，并在这一阶段把相对界降到上述
\(n_3\le8S_{12}+1\)（这是关闭下一层之前的中间状态）。

对新最高层 \(n_3=8S_{12}+1\)，入口以上的全部 \(S\ge4\) 也已经
排除。86 个尺寸和 48808 个赋值元组只留下
\((S,m_3)=(5,16)\) 的一个余因子；它固定
\((b_1,b_2)=(768,97)\) 与 \((s_1,s_2)=(-2,4)\)，随后
near-square 判别式满足 \(Y^2\equiv2\pmod3\)。第 27.15 节因此只
留下 \(S=2,3\) 的入口边界。

这两个边界现也已由独立有限证书关闭。严格的非 dominant 改进界
\(n_3\le7S+3\) 先排除 \(S=3\)，并把 \(S=2\) 压到
\(m_3=15\) 的取等锥；统一尾整除在该锥没有余因子。dominant 部分
分别产生 618、39710 个 denominator-tail 元组，二进位置、强制
resonance 与五进三分支把它们压到 114、27 个 tail-prefix 组合；
squarefree gap 只留下 2、8 个统一判别式，而精确整数平方根检查
验证十个均非平方。因此整层 \(n_3=8S_{12}+1\) 已排除，并得到开头
所列的中间界 \(n_3\le8S_{12}\)。

在新边界 \(n_3=8S_{12}\) 上，入口以上的结构也已经继续收缩。
当 \(S\ge11\) 时，非 \(b_3\) 二进主导位置全部排除；\(t_2=1\)
只留下 70 个有理尺寸和 51828 个必要赋值行。精确 floor-sum 模计数
先与 1000 个随机小盒的直接枚举对照，再验证所有余因子区间均为空，
所以这一子锥已经由有限证书关闭。

同一边界的 \(t_2\ge2\) 支仍是无界问题，但已经得到严格正规形：

\[
m_3=3S,\qquad d_3=5S,
\]

前两块除交换外只能有一个 denominator 长度为 1、numerator 长度为
\(S+1\)，另一个 denominator 长度为 \(S-1\)、numerator 长度为
1，并且

\[
\kappa=10^{2S}c,
\qquad c\in\{1,2,3,4,5,6,7,8\},
\qquad 10^{S-3}\mid b_3.
\]

这不是八个有限候选，而是八个前缀族；不过第 27.18 节又从

\[
F_-=10^{2S}\rho,
\qquad0<\rho<20000
\]

和两个精确 \(\mu/\nu\) 公式推出

\[
\frac{c10^{2S}+2G}{\gcd(c10^{2S},G)}\mid\rho Q.
\]

八核固定赋值把 gcd 商统一限制为
\(\gcd(c10^{2S},G)/c\le128\)。因此左边的 \(10^{2S}\) 增长与
右边的 \(10^S\) 高度发生严格矛盾，八个无界族全部关闭。当前得到

\[
n_3=8S_{12}\Longrightarrow S_{12}\le10,
\qquad
S_{12}\ge11\Longrightarrow n_3\le8S_{12}-1.
\]

在这一中间阶段，整个 \(8S\) 层只被压到 \(2\le S\le10\) 的有限
\(S\)-列表；这并不自动给出完整有限候选盒，所以当时还不能降低统一
相对界。

这个小切片中的入口上同型五进正规形也已进一步排除。对
\(t_2=1\)，56 个尺寸的 97693 个赋值行经同步 \(F_-\) 因子界、
精确余因子和真实 denominator factorization 只剩
\((b_1,b_2)=(768,97)\) 的一个尾核；near-square 判别式仍满足
\(Y^2\equiv2\pmod3\)。对 \(t_2\ge2\)，\(S\ge7\) 已由同一个
无界大除数矛盾排除，\(S=4,5,6\) 的真实分母有限证书也没有幸存者。
因此

\[
4\le S\le10,\quad n_3=8S,
\]

中的 \(b_3\)-二进主导唯一五进正规形全空。这里必须保留限定：普通
入口下 resonance、\(5\nmid b_3\)、\(\Delta_5^\pm\) 和部分其他
二进位置仍未处理。

第 27.21 节又把这些限定内的状态全部处理完毕。对 \(S\ge4\)，若
\(5\mid b_3\)，位数下界恢复 \(e_5=q_5\)，此后 resonance、
\(\Delta_5<0\)、\(\Delta_5>0\) 依次由唯一正规形、单因子高度与
primitive recovery 排除。若 \(5\nmid b_3\)，尾权只能退化为
\(2\cdot5^{3S}\)：大 \(S\) 直接违反尾高度，\(S=4,5,6\) 又与三个
精确二进剩余类矛盾。因此当前等号层结论加强为

\[
n_3=8S_{12}\Longrightarrow S_{12}\in\{2,3\},
\qquad
S_{12}\ge4\Longrightarrow n_3\le8S_{12}-1.
\]

第 27.22 节随后专门处理 \(S=2,3\)，但没有把固定 \(S\) 直接误作
完整有限盒。non-dominant 扇区分别强迫 \(m_3\ge14,21\)，而统一
denominator-tail 整除核在 \(m_3=10,17\) 后已经为空，所以可能无界的
prefix surplus 无需枚举。dominant 扇区才由
\(n_1+n_2\le S+2\) 真正有限化；1527、72092 个 tail rows 经二进
位置、两素数三状态、既约性与 squarefree gap 后，留下 703、38633
个非负统一判别式，精确整数平方根检查全部非平方。因此整个等号层
已经关闭，当前严格界为

\[
\boxed{n_3\le8S_{12}-1.}
\]

但这仍然不是 DD 全局空性；有限证书只覆盖严格有限化的 dominant
小尺寸，non-dominant 小尺寸由不含 numerator 枚举的尾整除排除，
其余大 \(S\) 等号层由无界论证关闭。更低的 \(n_3\le8S-1\) 区域
仍可随 \(S\) 无界，需要对自发 resonance 与两条 non-resonance 支
分别建立同样的主导项或高度矛盾。这一 gap-valuation / dominant-term /
height 思维也有可能被移植到 \(A_2\) 和 \(A_1\) 的剩余核中。

第 27.23 节又在这个界上取得了两项严格进展。首先，第 25 节原有的
\(S\ge5\) 取等排除，与 \(S=2,3\) 的完整尾表及
\(S=4,m_3=27\) 的零尾核合并，给出全局

\[
m_3\le6S+2,
\qquad
\text{non-dominant 时 }n_3\le7S+2.
\]

其次，最高允许层 \(n_3=8S-1\) 已全部进入 dominant 扇区。在
\(S\ge18\) 的五进入口以上，\(t_2\ge2\) 被压成 19、9、0 个
常数核，并由与第 27.18 节同型的大除数矛盾排除；\(t_2=1\) 则压成
45 个尺寸、15525 个 valuation rows，并由精确 floor-sum 余因子证书
排除。因此

\[
\boxed{
n_3=8S_{12}-1
\Longrightarrow
d_3=\max(s_1,s_2,d_3),\quad S_{12}\le17.
}
\]

这不是该层空性的证明，但第一次把当前最高允许层变成了同时限制
denominator 与 numerator 位数的完整有限原问题盒。下一步可以对这个
盒做分层证书；更低的 \(n_3\le8S-2\) 仍保留无界核心。

这个有限盒的两个最小尺寸现也已关闭。对 \(S=2,3\)，完整 dominant
tail 核分别有 2665、126669 行；两素数三状态、既约性与无溢出的
squarefree gap 把最终判别式数压到 24396、1582338，精确整数平方根
检查全部非平方。因此当前最高层进一步缩成

\[
\boxed{n_3=8S_{12}-1\Longrightarrow4\le S_{12}\le17.}
\]

对下一个尺寸 \(S=4\)，第 27.25–27.28 节先从 \(F_-\)、primitive recovery
与正拼接 gap 导出通用大除数

\[
\frac{\mathfrak L_F}{\gcd(\mathfrak L_F,Q)}\mid F_-,
\qquad
\mathfrak L_F=
\frac{\kappa(\kappa+2G)}
{\gcd(\kappa(\kappa+2G),\kappa+G)},
\]

它不要求 resonance。随后 squarefree gap 与四个完整有限证书排除
\(m_3=11,12,13,14\)：四层分别只剩
694825、10987773、714489、99342 个大整数判别式需要精确平方根
检查，全部非平方。余下 \(m_3=15,\ldots,21\) 的流式精确证书也没有
平方判别式，而 \(m_3=22,\ldots,26\) 的 primitive denominator-tail
核为空。因此

\[
\boxed{
S=4,\quad n_3=31
\Longrightarrow
\text{无 DD 候选},
\qquad
n_3=8S-1\Longrightarrow5\le S\le17.
}
\]

这里的 \(S=4\) 空性是明确有界的有限证书，不是 \(8S-1\) 整层空性，
更不是 DD 的全局空性。

对 \(S=5,n_3=39\)，第 27.29 节又以相同的精确流式引擎排除
\(m_3=22,\ldots,26\)，并证明 \(m_3=27,\ldots,32\) 的 primitive
denominator-tail 核为空。第 27.30 节再由 denominator-unit valuation
box 与完整两素数状态证书排除唯一最低层 \(m_3=14\)；第 27.31–27.32
节再以三个和七个严格位数形状的完整多精度判别式证书排除
\(m_3=15,16\)。因此这个尺寸
当前严格缩为

\[
\boxed{17\le m_3\le21,\qquad18\le d_3\le22.}
\]

这仍是明确有界的分层进展；\(S=5\) 尚未关闭，最高层还有
\(6\le S\le17\)，更低层仍可随 \(S\) 无界增长。

在那之前，严格的最终状态仍然是：

\[
\boxed{
\text{主不存在性命题高度受限、结构非常刚性，但尚未完成证明。}
}
\]
