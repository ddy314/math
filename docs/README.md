# 文档

本目录保存研究说明、证明记录和可复核工作流。数学主线从 [证明资料入口](proofs/README.md) 开始。

## 文档分层

- `proofs/exact-lift/`：本仓库唯一的**权威主证明树**；当前状态以其中的 `status.md`、三个分支 `README.md` 与规范专题为准。
- `proofs/external/`：外部仓库导入的研究材料。外部材料必须经过本仓库审计，不能凭原作者的状态标签直接升级主线结论。
- 根目录 `README.md`：仓库级入口。
- 根目录 `AGENTS.md`、`CONTRIBUTING.md`：证明记录、验证和修改规范。

证明文档中的“已严格完成”只表示对应局部命题在写明假设下闭合，不表示主不存在性定理已经完成。
